# ヒカカク時計 型番別LP調査

このフォルダを型番別LPの根拠資料の正本とする。

- `MODEL_RESEARCH.csv`: 16型番の調査・判定一覧
- `APPRAISAL_EVIDENCE.csv`: 採用候補、参考、除外を含む査定実績台帳
- `DECISIONS.md`: GO-A / GO-B / HOLDと制作条件
- `SOURCE_LEDGER.md`: 公式出典URLと解釈境界
- `MATERIALS.md`: 調査方針と制作時の遵守事項
- `LP_OUTPUTS.csv`: 16型番の実装ルートとQA状況
- `IMAGE_ASSETS.md`: ImageGen素材の共通方針と実装パス

未確認の価格は公開コピーへ移さない。LP側では `sourceUrl` と `sourceCheckedAt` を追跡可能な形で残す。
