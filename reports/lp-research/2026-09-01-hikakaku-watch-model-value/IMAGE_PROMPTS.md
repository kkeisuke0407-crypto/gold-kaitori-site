# 生成画像プロンプト記録

生成方法: Codex組み込みImageGen

## ヒーロー画像 共通プロンプト

用途はスマホ中心のLPヒーロー。縦2:3、ウォールナット天板、時計を右側に大きく配置し、左側はHTML見出し用の明るい余白。柔らかな窓光、信頼感のある中古高級時計の編集写真。人物・箱・余分な時計・透かし・キャプションは入れない。モデル別に次を指定した。

- サブマリーナ 14060M: 黒ベゼル、黒文字盤、ノンデイト、3連ブレス
- デイトジャスト 116234: フルーテッドベゼル、白ローマ文字盤、ジュビリー系ブレス、日付拡大
- デイトナ 116500LN: 黒セラミックベゼル、黒文字盤、3インダイヤル
- GMTマスターII 116710LN: 黒24時間ベゼル、黒文字盤、緑GMT針、日付拡大
- エクスプローラーI 214270: スムースベゼル、黒文字盤、3・6・9インデックス

## 入力画面画像 共通プロンプト

用途は「実際に入力する内容」セクション。縦2:3、左に濃紺フレームのスマホ、右に時計正面・裏面・箱・保証書・余りコマの2×2写真。白・薄青・濃紺・オレンジで既存LPに合わせ、以下の日本語を画像内へ正確に文字入れする。

- `ヒカカク！`
- `ブランド　ROLEX`
- `モデル　<モデル名>`
- `型番　<型番>`
- `状態　使用感あり`
- `<モデル別の傷>`
- `動作　正常に動作`
- `付属品　箱あり`
- `保証書あり`
- `余りコマあり`

モデル別の文字は、サブマリーナ / 14060M / ベルトに細かい傷あり、デイトジャスト / 116234 / ベゼルとベルトに細かい傷あり、デイトナ / 116500LN ブラック / ベゼルとケースに細かい傷あり、GMTマスター II / 116710LN / ベルトに細かい傷あり、エクスプローラー I / 214270 / ケースとベルトに細かい傷あり。
