60代の断捨離、何から始める？無理なく続ける順番

PR

家中を一気に片付ける必要はありません。

まずは、引き出し1段など小さい場所から。

まねきや公式サイトへ 手放す前に価値だけ確認する 昔のアクセサリーなど、処分に迷う物がある方へ

小さい場所から、4つに分ける

  1. 今も使う

    → 残す

  2. 思い入れがある

    → 残す

  3. 家族へ渡す

    → 譲る

  4. 何年も使わない

    → 手放す候補

迷った物は、「保留箱」に入れておけばOKです。

「もう使わない」と「価値がない」は別

昔買った、こんな物はありませんか。

  • 指輪・ネックレス
  • 時計
  • 金貨
  • 宝石

使わなくなっていても、価値が残っている場合があります。

手放すか迷う物は、価値も判断材料の1つにできます。

まねきや公式サイトへ 手放す前に今の価値を確認する 査定額を見て「やっぱり残す」でもOK

ここから詳しく知りたい方へ

始める場所は「短時間で終わる所」

最初から押し入れ全体や家一軒を片付けようとすると、物量の多さに疲れてしまいます。

  • 引き出し1段
  • 洗面台
  • クローゼットの一角
  • バッグ1つ
  • アクセサリーケース1つ

「保留箱」をひとつ作る

迷った物の置き場を先に決めておくと、片付けが途中で止まりにくくなります。

断捨離は「全部売る」ことではありません

  • 今でも好きなら残す
  • 子どもや孫に渡したいなら残す
  • 大切な思い出があるなら保管する

それでも何年も使っておらず、今後も使う予定がない物だけを、手放す候補にします。

査定額を確認した結果、「やっぱり残そう」でも大丈夫です。

壊れたアクセサリーも一度確認

  • ネックレスが切れている
  • 指輪が変形している
  • 石が取れている
  • ピアスが片方しかない

アクセサリーとしては使いにくくても、金やプラチナが使われていれば素材として査定対象になる場合があります。

留め具や指輪の内側に「K18」「K24」「750」などがあれば、金の純度を示す刻印として使われている可能性があります。

刻印だけで本物と決めつけない

刻印があっても、それだけで真正品とは断定できません。よく分からない物は、捨てる前に専門店で素材を確認する方法があります。

手放す前の確認先は、この4点で選ぶ

  1. 査定だけでも利用できる

  2. 壊れた品にも対応している

  3. 金か分からなくても相談できる

  4. 手数料が分かりやすい

よくある質問

金かどうか分からなくても、査定してもらえますか。

はい。まねきやでは専門機器を使った査定を案内しているため、金か分からない段階でも相談できます。

切れたネックレスでも査定できますか。

できます。金は素材そのものに価値があるため、変形・切れ・片方だけでも重さと純度で査定されます。

刻印が読めなくても大丈夫ですか。

大丈夫です。X線分析で含有量を測定できるため、刻印が消えている品も査定できます。

査定したら、売らないといけませんか。

いいえ。査定額を確認してから判断できます。まねきやはキャンセル料も無料と案内しています。

「最大20%UP」なら、必ず20%上がりますか。

いいえ。「最大」であり適用条件があります。電話で自分の品物が対象か確認してください。

「K18」とは何ですか。

金の純度を表す記号です。K24が純金に近く、K18は金が75%含まれることを示します。

金メッキでも売れますか。

メッキは表面に薄く金を塗ったもので、素材としての価値はごく僅かです。査定額が付かない場合があります。

手数料はかかりますか。

まねきやは金製品の手数料を無料にするキャンペーンを実施中です。表面の単価ではなく、手数料込みの最終手取りで比べてください。

身分証は必要ですか。

必要です。古物営業法により本人確認が義務付けられています。

遺品でも売れますか。名義が違いますが。

相続した品物は相続した方の所有物として扱われます。ご本人以外の持ち物の売却には対応できません。

未成年でも売れますか。

18歳未満の方は、保護者の同伴または同意書が必要です。

3社とも査定に出して比べてもいいですか。

問題ありません。査定は無料と案内されているため、複数社に同じ品を見せて比べる方法もあります。
