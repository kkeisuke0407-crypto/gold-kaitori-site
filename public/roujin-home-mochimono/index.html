老人ホームの持ち物、何が必要？入居前に準備する物を確認

PR

まずは、衣類・日用品・薬・毎日使う物から準備します。

持ち込みルールは施設ごとに違うため、入居先への確認が必要です。

まねきや公式サイトへ 家に残す価値不明品を確認する 入居後に使わないアクセサリーなどがある方へ

まず準備するもの

  • 衣類（普段着・下着・パジャマ）
  • 洗面用品
  • 薬・お薬手帳
  • 眼鏡・補聴器
  • 日常的に使う身の回り品

家具・家電・貴重品などのルールは施設ごとに異なります。

次に考えるのは「家に残す物」

持っていかない物は、5つに分けます。

  1. 本人が残す

  2. 家族が預かる

  3. 家族が使う

  4. 処分する

  5. 価値が分からないので保留

本人も使わない。家族も引き取らない。それでも価値が分からない指輪・時計・宝石・金貨などがあれば、処分前に価値だけ確認できます。

まねきや公式サイトへ 自宅に残す品の価値を確認する 査定額を見てから、残す・売るを決めてOK

ここから詳しく知りたい方へ

持っていく物をもう少し詳しく

衣類

  • 普段着・下着・パジャマ・靴下
  • 羽織もの、季節に応じた衣類

収納できる量は施設によって違います。必要な枚数を事前に確認しておくと安心です。

日用品

  • 歯ブラシ・コップ・タオル
  • 洗面用品、ティッシュなど

施設側で用意される物もあります。重複して買わないよう確認しましょう。

薬・医療関係

普段飲んでいる薬やお薬手帳など、施設から案内されたものを準備します。

思い出の品

家族写真や小さな置物など、本人が安心して過ごせる物を少量持っていくのもひとつです。

施設によって持ち込みルールは違います

家具・家電・刃物・火気を使う物、現金や貴重品の管理は、施設ごとに条件が異なります。「これくらいなら大丈夫だろう」と自己判断しないでください。

昔のアクセサリーや時計は、処分する前に一度確認

何十年も使っていなかったり、デザインが古かったりすると「もう価値はないだろう」と思ってしまいがちです。

でも、金やプラチナなどの貴金属は、素材そのものが査定対象になることがあります。

こんな物も、すぐ捨てない

  • 切れたネックレス、曲がった指輪
  • 石が取れたリング、片方だけのピアス
  • 金色だけれど、素材が分からない物
  • 昔の金貨・記念金貨

刻印だけで本物と決めつけない

刻印があっても、それだけで真正品とは断定できません。素材が分からない場合は、自分で決めつけず専門店で確認する方法があります。

本人の持ち物は、本人の意向を確認してから

老人ホームへ入居するからといって、家族の判断だけで本人の持ち物を処分するのは避けましょう。

本人が判断できる場合は、「これは持っていく？」「家族に渡していい？」「処分して大丈夫？」と確認しながら進めるのが基本です。

家に残す品を見てもらうなら、この4点を確認

  1. 出張で対応してもらえる

  2. 古い・壊れた品も見てもらえる

  3. 金か分からなくても相談できる

  4. 査定後にキャンセルできる

よくある質問

金かどうか分からなくても、査定してもらえますか。

はい。まねきやでは専門機器を使った査定を案内しているため、金か分からない段階でも相談できます。

切れたネックレスでも査定できますか。

できます。金は素材そのものに価値があるため、変形・切れ・片方だけでも重さと純度で査定されます。

刻印が読めなくても大丈夫ですか。

大丈夫です。X線分析で含有量を測定できるため、刻印が消えている品も査定できます。

査定したら、売らないといけませんか。

いいえ。査定額を確認してから判断できます。まねきやはキャンセル料も無料と案内しています。

「最大20%UP」なら、必ず20%上がりますか。

いいえ。「最大」であり適用条件があります。電話で自分の品物が対象か確認してください。

「K18」とは何ですか。

金の純度を表す記号です。K24が純金に近く、K18は金が75%含まれることを示します。

金メッキでも売れますか。

メッキは表面に薄く金を塗ったもので、素材としての価値はごく僅かです。査定額が付かない場合があります。

手数料はかかりますか。

まねきやは金製品の手数料を無料にするキャンペーンを実施中です。表面の単価ではなく、手数料込みの最終手取りで比べてください。

身分証は必要ですか。

必要です。古物営業法により本人確認が義務付けられています。

遺品でも売れますか。名義が違いますが。

相続した品物は相続した方の所有物として扱われます。ご本人以外の持ち物の売却には対応できません。

未成年でも売れますか。

18歳未満の方は、保護者の同伴または同意書が必要です。

3社とも査定に出して比べてもいいですか。

問題ありません。査定は無料と案内されているため、複数社に同じ品を見せて比べる方法もあります。
