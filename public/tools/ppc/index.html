出稿前判定

成果条件と市場CPCから、払える上限CPCと必要なLP→アフィCTRを逆算します。

この画面の読み方
  • 損益分岐CPC：これ以上払うと赤字になるクリック単価。
  • 上限CPC：目標ROASを満たしたまま払える上限。損益分岐CPC ÷ 目標ROAS。
  • 必要LP→アフィCTR：市場CPCで戦うために、LP来訪者の何%がアフィリンクを踏む必要があるか。100%を超えたら構造的に不可能なので出稿しない。
  • CPC余裕率：上限CPC ÷ 市場CPC。1.0未満は改善前提、0.8未満は原則見送り。
  • 確信度を1未満にすると、広告主CVRが下振れした「弱気シナリオ」でも黒字かを見ます。GO判定は弱気シナリオ基準です。

入力

判定

数値を入れると自動で判定します。

シナリオ比較 広告主CVRの確信度に応じた振れ幅

キーワードエクスプローラ

KWごとに必要CTRを逆算し、CORE / OPPORTUNITY / DISCOVERY / EXCLUDE に仕分けます。

データの入れ方
  1. Google広告 → ツール → キーワードプランナー でKW候補を取得し、CSVでダウンロード。
  2. 下のファイル選択でそのCSVを読み込む（列は自動判定します）。
  3. または、テキスト欄に キーワード, 月間検索数, CPC をタブ/カンマ区切りで貼り付け。

バケット判定は数式で行います。AIの意図スコアがあれば 商用意図 想定LP CTR 列を足すと精度が上がります。

運用診断

実績からボトルネックを特定し、損益分岐までの最小改善経路と撤退可否を出します。

この判定のロジック
  • SCALE は「実績ROASが目標を超えている」だけでは出しません。成果件数から求めたベイズ信用区間の下限でも目標を超えている場合のみです。CV数件の偶然でスケールする事故を防ぎます。
  • CV0の撤退は固定クリック数だけでなく、「損益分岐に必要なCVRが本当なら、この連続ゼロが起きる確率」で判断します。サンプルが小さいうちは撤退しません。
  • IMPROVE / STOP は、各レバー（CPC・LP CTR・CVR）を損益分岐まで動かすのに必要な改善幅から実現性スコアを出して分けます。

判定
