LPパーツ案（見直し）

パーツ辞典の見直し案です。まだどのLPにも使っていません。選んでもらったものだけ辞典に入れます。

1. 見た目が似ている4つの描き分け ／ 2. 指摘されたパーツの「削除」か「代わりの案」 ／ 3. 調べて出した新しいパーツ

  • 1. 見出し系の描き分け
  • 2. 削除・代わりの案
  • 3. 新しいパーツ案

1. 見出し系の描き分け

今は「中見出し・小見出し・つかみ・言い切り」がどれも左に金の線が付いた形で、見分けがつきません。役割ごとに形を変えます。

代わりの案中見出し（h3）→ 番号＋下線

左の線をやめて、番号の丸と全幅の下線にします。「ここから小分けの話」だと一目で分かります。

案

1待っているうちに、値下がりする

削除小見出し（ui-h4）

中見出しと役割がかぶるので廃止。見出しは h2 と h3 の2段だけにします。

代わりの案つかみ（kin-intro）→ 心の声カード

見出しと違う「話し言葉」だと分かるよう、灰色の紙に大きなカギカッコ、上に「こんな気持ち、ありませんか？」のラベルを付けます。

案

こんな気持ち、ありませんか？

もう少し上がってから売ろう

代わりの案言い切り（kin-punch）→ 上下の線だけ

箱も色もやめて、上下の細い線と中央寄せの大きな文字だけに。見出しとも枠とも違う「ひと呼吸の言い切り」になります。濃紺のまとめ帯の代わりもこれで兼ねます。

案

決めるのは、
金額を知ってから。

2. 削除・代わりの案

指摘された14個です。役割がかぶるものは削除、残す価値があるものは形を変えます。

代わりの案重さ別の目安 → 値札

「今いくら？」の答えを値札の形に。見た瞬間に「値段の話」と分かります。

案

18金の喜平　今日の目安

50g約89万円

100g約178万円

今日の18金の値段×重さの目安です

代わりの案（2つを1つに）損の差＋値動きの年表 → 「3月 → 今日」

2つとも「下がった」を見せる部品なので1つにまとめます。左右に並べて矢印、下の赤い帯に差額。

案

3月3日（最高値）29,969円/g
▶
今日24,150円/g

18金の喜平50gなら 約22万円 減った計算

代わりの案件数の増加 → 新聞記事風

国民生活センターなどの公的な発表を「ニュースの切り抜き」の形で。数字だけより「本当に起きていること」に見えます（記事LPの「ニュース型」）。

案

国民生活センター 発表

貴金属の買取トラブル、
5年で約5.7倍に

「査定だけのつもりが、断りきれずに売ってしまった」などの相談が増えています。

2026年9月2日公表／2020年度165件→2025年度937件

削除数字3つ（ui-num）

3列カードと役割がかぶるので廃止。数字を見せたいときは値札か「0円スタンプ」を使います。

代わりの案料金の一覧 → 0円スタンプ

表ではなく、はんこの形で「0円」を3つ並べます。読まなくても「お金がかからない」が伝わります。

案

査定料0円
出張料0円
キャンセル料0円
削除ビフォー・アフター（ui-ba）

中身がぼんやりしやすいので廃止。「知っている／知らない」の差は、下の「受取額の明細」で具体的に見せます。

代わりの案注意の枠 → ⚠ 見出し帯つき

薄いピンクの枠だとポイント枠と似て見えるので、上に赤い帯と⚠を付けます。×のチェックリストはこのまま残します。

案

お店で売ったら、取り消せません

お店に持ち込んで売った場合、クーリング・オフはできません。

削除赤い帯（kin-urge）

強すぎて浮くので廃止。呼びかけは「心の声カード」で。

代わりの案結論ボックス → まとめ＋ボタン直結

まとめを読んだ直後に押せるよう、番号付き3行とボタンを1つの枠に入れます。

案

ここまでのまとめ

  1. 喜平は、お店で金額が変わる
  2. 待つほど得とは限らない
  3. 聞くだけなら0円。売らなくてOK
今の金額を電話で聞く
削除濃紺のまとめ帯（kh-bridge）

代わりの案よくあるお店との違い → ○×対照表

文字の表をやめて、大きな○と×だけで比べます。50代以上でも一瞬で読めます。

案

左右2列だと文字が小さく詰まるので、1列の「向いている人」と、下に小さく注意を1行。

案

表で他社を並べると成果にならないクリックが増えるので、質問1つで答えが出る形に。答えは「金ならまねきや」に自然に着地します。

3. 新しいパーツ案（調べて出したもの）

記事LPでよく使われる「診断」「ニュース型」「権威」「マイクロコピー」「追従ボタン」などをもとに、金買取×50代以上向けに絞りました。特に電話への不安をなくす部品を多めにしています。

新しい案受取額の明細

「最後にもらえる金額」を買取明細の形で見せます。喜平LPの一番伝えたいこと（今日の値段ではなく、全部でいくら）が1枚で伝わります。

案

買取明細（例）

18金の喜平 50g891,050円

手数料10%のお店なら−89,105円

受取額（手数料0円）891,050円

※ 仕組みを説明するための計算例です。実際の金額は査定で決まります。

新しい案電話で聞くことメモ（付箋）

電話が苦手な人向け。「これだけ聞けばいい」を付箋の形で。電話ボタンの直前に置くと、押すハードルが下がります。

案

電話では、この3つだけ

  1. 全部でいくらになりますか？
  2. 手数料は引かれますか？
  3. 断っても費用はかかりませんか？
新しい案電話の流れ（会話の例）

「電話したら何を聞かれるの？」の不安を先に消します。3往復まで。

案

キャンペーンの締切を、日めくりの形で。残り日数は固定の締切日から自動計算し、過ぎたら消えます。
