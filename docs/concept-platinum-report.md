# 新LPコンセプト：プラチナ指輪「適正額レポート」

> 既存LP・競合の改善/焼き直しではない。**広告データの検索意図を中心に据えたゼロからの新コンセプト**。
> 一次根拠：`docs/ad-data-analysis.md`（実広告データ）／`docs/design-system.md`（競合実物9枚＋2ジャンル調査）。
> 公開先：`/pt-shindan/`（既存`/platinum/`はA/B用に温存）。融合方針＝**①適正価格のものさし(自衛ツール) × ②鑑定書体験**。

---

## 1. なぜこの形なのか（全データの収束点）

| データ層 | 結論 |
|---|---|
| 広告(実) | 来訪者は**売却直前**。本当に欲しいのは ①**自分の品の適正額** ②**買い叩かれない確信**。純度を打つ＝品を手に持つ本気層。結婚指輪＝感情価値。 |
| 競合(実物) | 全社「最高値!無料!即日!」で**主張がインフレ→不信が増幅**（"なんぼや 手数料"で疑う理由）。空き地＝**透明性／ユーザー側の確信**。 |

**CVを止める壁は「どの店が高いか」ではなく「自分の指輪の"適正額"が分からないから動けない」恐怖。**

→ 既存LP・競合は全部「**店を売る**」構造（我々は最高値→査定して）。
**新コンセプトは主語を反転：「あなたの品」を主役にし、ユーザーを"武装"させる。送客は信頼の結果として起きる。**

---

## 2. コンセプト定義

### 名称
**「プラチナ指輪 適正額レポート」** — 査定に行く前に、あなたの指輪の"適正額"と"騙されないための数字"を3分で持つ。

### 中心となる成果物（artifact）
ユーザーが数項目を入力すると、**証書風のパーソナル「適正額レポート」**が生成される。
レポートには：
- **適正額レンジ**（単一の額でなく、地金下限〜状態込み上限）
- **算出の内訳**（当日単価 × 重さ × 純度。なぜその額かを開示）
- **買い叩きライン**（これを下回る提示は買い叩き、という防衛ボーダー）
- **店に言うべき一言**（武装：このレポートを根拠に何を聞くか）

このレポート自体が、信頼の証＝感情価値品の品位ある扱い＝CTAの担い手。**①ものさし(判定＋防衛)を②鑑定書(成果物体験)の形で返す**＝融合。

### 一行コンセプト
> **店の宣伝を読むのではなく、"あなたの指輪の鑑定書"を自分の手で作る。**

## 3. 構造（既存テンプレとの断絶）

既存・競合＝「相場表→概算→比較→CTA」の**機能の積み重ね**。
新＝「**レポートを作って読む一連の体験**」として再設計。

```
① FV：判定の約束
   「あなたのプラチナ指輪の"適正額"を3分で。査定前に、騙されない数字を持つ。」
   レポートのチラ見せ(証書ビジュアル) + CTA[診断を始める][電話で聞く]
   + 本日のPt単価(信頼の起点として小さく)

② 適正レンジ診断【核心＝ものさし】
   刻印▼ / 重さ□g / 石の有無 / 種類 を入力
   → 横長の"ものさし"UIで [買い叩きゾーン赤 ─ 適正ゾーン緑 ─ あなたの位置▲] を可視化

③ 適正額レポート【核心＝鑑定書】 ← 生成される成果物
   証書風カード：適正額レンジ / 内訳(単価×重さ) / 買い叩きライン / 状態メモ
   [このレポートを持って相談する] CTA

④ 武装ブリーフィング【自衛】
   "店があなたを買い叩く3つの手口"：単価下げ / 後出し手数料 / 即決圧力
   "このレポートを根拠に、こう聞けば負けない"（店に言う一言を提示）

⑤ テストに通った相談先【送客・PR】
   武装済みユーザーに、適正額に正直に向き合う相手を提示
   👑まねきや(手取り重視/1位) / 🥈おたからや(店舗網/2位)。PR明示・順位は適性で正当化

⑥ あなたの品も対象 → 安心/流れ → 最終CTA(レポート再掲) → FAQ
⑦ スマホ下部 固定CTAバー
```

**断絶ポイント**：相場表・概算が「主役の体験」に昇格し、比較は「武装後の自然な選択」に降格。店主語→品主語へ反転。

## 4. デザインシステム（オリジナル：鑑定書 × 計器）

競合の「赤アグレッシブ」でも「青クリーン」でもない**第3の見た目＝"信頼できる診断器/鑑定書"**。

### 配色
```
地色      : #FBFAF7（温かみのある紙白）
インク     : #1A1614
プラチナ寒色: #3E5765 / #6B8794（金属の信頼）
鑑定の箔   : #C8A24A（証書のゴールドシール／枠の差し色のみ）
主CTA(行動): #1E6E4B（深緑）/ hover #18583C ← 比較型は緑が効く(実物根拠)
適正ゾーン : #2E7D52（緑）／買い叩きゾーン : #C0492F（赤）／あなたの位置 : #1A1614▲
ハイライト : 背景 rgba(200,162,74,.12) / 枠 #C8A24A
```

### モチーフ（このコンセプトの署名）
- **適正額のものさし**：横長バンド `[赤=買い叩き] [緑=適正] ▲あなた`。**競合の誰も持っていない視覚資産**。
- **鑑定書カード**：上質紙テクスチャ／箔押し風シール「適正額レポート」／罫線枠／番号(発行No.風)。

### タイポ
- 本文：Noto Sans JP（既存踏襲）
- 鑑定書見出し・適正額：**Noto Serif JP**（明朝）で品位と信頼＝結婚指輪の感情価値に対応。
- 金額：tabular-nums・nowrap・特大（競合の核＝数値最大）。

### コンポーネント規則
```
見出し  : 鑑定書系=明朝/その他=ゴシック。数値は見出しより大。
ものさし : 高さ44px帯・3ゾーン色分け・▲マーカーがアニメで移動。
レポート : 紙白カード+箔枠+シール。適正額は明朝特大。内訳は罫線テーブル。
ボタン  : 主CTA深緑/全幅/角丸12/☎or→。直下に「無料・その場で」。
比較    : 1位👑金枠突出/2位🥈銀控えめ(既存 knowledge 踏襲)。PRチップ。
固定バー: SP下部2分割[☎電話で聞く(深緑)|診断する(濃色)]。
```

## 7. このコンセプトが勝てる理由（要約）

- 検索意図①(額)②(騙されたくない)を、サイドの相場表ではなく**ページの中核商品**にした。
- 競合の空き地（透明性・ユーザー側の確信）を**"あなた専用レポート"という独自体験**で占有。
- 結婚指輪の感情価値に、**鑑定書の品位**で応える。
- 武装→送客の論理で、CTAが「売り込み」でなく「当然の次の一手」になる＝CVが理性的に起きる。
- デザインが赤/青どちらでもない**第3の信頼ビジュアル**＝競合と並べて埋もれない。
