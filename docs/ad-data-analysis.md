## ① 検索ユーザー心理（検索語句から）

実データの検索語句は、ほぼ**2つのクラスタ**に集約される。第3クラスタはほぼ無反応。

### クラスタA：プラチナ／指輪の「価格・相場」系（最大ボリューム）
例：`プラチナ 指輪 買取`(84表示/11クリック)、`pt900 指輪 買取 価格`、`pt950 指輪 買取 価格`、
`プラチナ 900 指輪 買取 価格`、`プラチナ 指輪 いくら で 売れる`、`結婚 指輪 売る プラチナ`

- **何を知りたいか** → 「**自分のこの指輪は、いくらになるのか**」。pt900 / pt950 / 950 / 1000 と純度を具体的に打ち込む＝品物を手に持って、目の前で調べている。
- **何が不安か** → 相場が分からず「**安く買い叩かれること**」。`いくらで売れる`という言い回しに、相場の自信のなさが出ている。
- **何を期待してクリックするか** → 「**このページなら、うちの指輪の概算額がすぐ分かりそう**」という期待。

### クラスタB：手数料＝「損したくない／騙されたくない」系
例：`18金 買取 手数料`(CTR33%)、`金 を 売る 手数料`、`金 売る 時 手数料`、`金 買取 手数料 無料`、
`金 売却 手数料`、`なんぼや 金 買取 手数料`、`大吉 金 買取 手数料`、`コメ兵 金 買取 手数料`

- **何を知りたいか** → 「**結局いくら引かれるのか＝手取りはいくらか**」。
- **何が不安か** → 「**無料と書いてあっても裏で抜かれるのでは**」「**店ごとに手数料が違うのでは**」という強い不信。`なんぼや/大吉/コメ兵 + 手数料`と**特定業者名＋手数料**で調べている＝有名店すら疑っている。
- **何を期待してクリックするか** → 「**手数料の本当のところ、手取りベースの正直な説明**」。

### クラスタC：刻印なし・素材不明系（今回ほぼ無反応）
`刻印 なし 金 買取`等。表示5・クリック0。**今回の検索需要には乗っていない**。

> **心理サマリ：** 今回のユーザーは「金を売る」という決断はほぼ済んでいて、
> **(A)うちの品はいくらか／(B)その額から損せず手取りを最大化できるか** を確かめにきている。
> いわゆる情報収集の入口段階ではなく、**売却直前の最終確認フェーズ**。

### 高意図の共通項（実データから抽出）
1. **純度を具体指定**（pt900 / pt950 / 950 / 1000 / 18金）＝品物が手元にあり、本気度が高い。
2. **「価格」「相場」「いくらで売れる」**が付く＝金額確認が一次目的。
3. **「手数料」**が付く＝手取り・損得が決済前の最終関門。

### CVに近そうな語句（優先的に取りに行くべき）
データの傾きから、最もCVに近いのは以下の交差点：
- **「pt900／pt950／18金 など純度指定」×「買取 価格／手数料」** の複合語句。
- 特に `pt900 指輪 買取 価格`・`18金 買取 手数料`・`プラチナ 指輪 買取` は配信量とCTRの両立があり、**主戦場**。

## ③ ユーザーの本当の目的（優先順位）

選択肢「売りたい／相場を知りたい／騙されたくない／高く売りたい」を、実データで順位付けする。

| 順位 | 目的 | 実データ上の根拠 |
|---|---|---|
| **1位** | **相場・自分の品の額を知りたい** | ほぼ全語句に「価格／相場／いくらで売れる」。純度を具体的に打つ＝目の前の品の概算が知りたい。これがクリックの入口。 |
| **2位** | **騙されたくない／損したくない** | 手数料クラスタの存在、しかも「無料」「なんぼや/大吉/コメ兵＋手数料」と業者名で疑う行動。CTR33%と高反応＝痛点。 |
| **3位** | **（前提として）売りたい** | 「相場」だけでなく「買取」を必ず併記＝情報収集でなく売却行動の直前。売る意思は既に固まっている。 |
| **4位** | **高く売りたい** | 1位+2位の裏側にある最終ゴール。ただし表面の検索語は「高く」より「いくら／手数料」で表現される。"高く"を直接謳うより"正確な額＋手取りが最大"で証明する方が刺さる。 |

> **核心：** ユーザーは「相場を知りたい（1位）」を入口に、「損したくない（2位）」をクリアできれば売る（3位）。
> "高く売れます"という売り文句（4位）を前面に出すより、**「あなたの品はいくら」＋「手数料で引かれず手取りが残る」**を見せる方がCVに直結する。

## ④ LPに必要な要素（広告データ根拠で3分類）

### 【必須要素】※データが直接要求しているもの
1. **純度別の概算価格／当日相場（pt900・pt950・18金・k18）を、ページ最上部で即提示**
   - 根拠：クリック語句がほぼ全て「価格・相場・純度指定」。来訪者の一次目的そのもの。FV(ファーストビュー)で「いくらか」に答えないと即離脱。
2. **手数料＝0、かつ"手取り＝査定額"の明言**
   - 根拠：手数料クラスタのCTRが最高水準（18金買取手数料33%）。業者名＋手数料で疑っている層。
   - 「手数料無料」だけでは弱い（競合も全員言う＝後述⑤）。「**提示額からの差引一切なし／グラム単価で勝負**」まで踏み込む。
3. **品物別の概算がその場で分かる導線（簡易計算 or 重さ×当日単価の早見表）**
   - 根拠：`いくらで売れる`の検索心理に最短で答える。問い合わせ前に"見込み額"を持たせるとCVの心理障壁が下がる。
4. **電話 と WEB査定予約 の2系統CTA**
   - 根拠：実際の広告説明文も「電話相談またはWEB査定予約へ」で運用済み。即決層＝電話、検討層＝WEB。両方を常時表示。
5. **結婚指輪・古い指輪・コンビ・刻印薄でもOKの受容メッセージ**
   - 根拠：`結婚指輪 売る`『金プラチナコンビ指輪買取』『プラチナ刻印買取』等が出現。「うちの品も対象か」の不安を消す。

### 【あると良い要素】
- **業者比較を意識した手数料の正直な解説**（「無料の落とし穴＝単価を下げて回収する店がある」を逆手に取り、自社の正直さを証明）。手数料クラスタは比較検討中。
- **大阪・東京・愛知・神奈川中心の店舗／対応エリア表示**（地域データで都市部に反応集中）。
- **査定実績（pt900 ◯g→◯円 等の実例）**。「いくらで売れる」への具体回答。
- **スピード感（最短即日・その場現金）**＝売却直前フェーズに効く。

### 【不要・優先度低の要素】
- **刻印なし・素材不明を主役にした訴求**：今回需要ゼロ（5表示0クリック）。サブの安心材料に留め、メインに置かない。
- **金の豆知識・歴史・金が上がっている市況コラム等の読み物**：来訪者は売却直前で「自分の額」を見にきている。長文教育コンテンツはFVを押し下げるだけ。
- **過剰なブランド世界観・デザイン演出**：CV最優先。額と手取りの即答を邪魔する装飾は削る。

## ⑤ 競合調査（金買取／相場／18金／査定 関連の上位LP）

調査対象：おたからや・なんぼや・大吉・バイセル・リファスタ・七福神・高く売れるドットコム等の上位ページ。

### 全競合共通の要素（=これが無いと土俵に乗れない）
- **当日の金・プラチナ買取相場（1gあたり、純度別）を掲載**（pt900≒4,700〜4,800円/g台など日次更新）。
- **「手数料無料」表記**（田中貴金属・三菱マテリアル等を除き大半が無料を掲げる＝差別化にならない）。
- **無料査定・査定方法（店頭/出張/宅配）の明示**と電話番号。
- **査定の流れ（4〜5ステップ）**、買取実績、安心訴求（古物商許可・実店舗数）。

### 上位競合だけが持つ要素
- **1gあたり買取価格の"ランキング/比較"**（ウリドキ・比較メディアが「g単価で即解決」と打ち出す）。
- **純度別・商品別の詳細な参考買取価格ページ**（pt900指輪○g→○円の実例を大量掲載）。
- **店舗網・実績の規模感**（おたからや1,740店舗、専門査定員 等）でブランド信頼を担保。

### 競合があまり使っていない＝差別化チャンス（今回データと合致）
1. **「手数料無料」ではなく「手取り額の最大化を約束」**：競合は無料止まり。
   実データの不信（業者名＋手数料で疑う）に対し、**"提示額＝受取額。単価で勝負、後出しゼロ"**と踏み込むと刺さる。
2. **入力前に概算が出る"その場見積り"体験**：多くの競合は「無料査定へ」で実額は問い合わせ後。
   `いくらで売れる`需要に対し、**重さ×当日単価の簡易シミュレータ**を置くと一歩先に行ける。
3. **"無料の落とし穴"を自ら開示する正直訴求**：競合コラムは指摘するがLP本体では避けがち。
   LP本体で「単価を下げて手数料無料に見せる店に注意」と書き、自社単価を並べる＝不信層をそのまま取り込める。
4. **プラチナ指輪に特化したFV**：競合は「金買取」総合で薄まりがち。今回の最大流入はプラチナ指輪。
   **プラチナ指輪専用の入口**を作ると、最大ボリューム語句との一致度で勝てる。

## ⑥ 最もCV率が高くなりそうなLP構成（デザインでなくCV最優先）

実データ（プラチナ指輪×価格／手数料×手取り）＋競合の隙（手取り保証・その場概算・正直訴求）で構成。

```
[FV：ファーストビュー＝離脱を止める1画面]
  ・見出し：「あなたのプラチナ・金、今日いくら？ 手数料0円・提示額がそのまま手取り」
  ・当日の純度別買取単価（pt900/pt950/18金/k18）を数値で即提示
  ・CTA①（電話：今すぐ概算を聞く）/ CTA②（WEB査定予約：30秒）を横並び固定
  ・サブコピー：結婚指輪・古い指輪・刻印薄・コンビもOK

[ブロック1：その場で概算が分かる] ← 検索心理「いくらで売れる」へ最短回答
  ・重さ × 当日単価の簡易シミュレータ or 純度別の早見表
  ・「pt900 指輪 約4g → 約○○円」など実例3〜4点

[ブロック2：手数料の正直な話] ← 手数料クラスタ（不信層）を捕捉
  ・「手数料0円。査定額からの差引は一切なし＝提示額＝手取り」
  ・"無料の落とし穴"開示：単価を下げて無料に見せる店に注意 → 自社のg単価を提示
  ・他社にありがちな減額項目との対比（後出し手数料/出張費/キャンセル料＝当社ゼロ）

[ブロック3：あなたの品も対象] ← 「うちの品は対象?」の不安除去
  ・結婚指輪/コンビ/刻印薄/壊れ/片方ピアス/素材不明も査定対象（※刻印なしはサブ扱い）

[ブロック4：簡単・安心・速い] ← 売却直前フェーズの背中押し
  ・査定の流れ（最短ステップ）/ 最短即日・その場現金
  ・古物商許可・実績・査定員の信頼担保

[ブロック5：CTA再掲（電話／WEB予約）]
  ・「金額を聞いてから売るか決められます」＝決断リスクを下げる一文
  ・対応エリア（大阪・東京・愛知・神奈川 等の都市部を前面）

[追従バー：スマホ下部固定のCTA（電話/WEB）を常時表示]
```

設計の根拠まとめ：
- FVで「いくらか」即答＝目的1位に最短。手数料0＋手取り保証＝目的2位を同時解消。
- 「金額を聞いてから決められる」＝売却（3位）への心理障壁を最小化。
- "高く売れる"を連呼せず、**正確な額×手取り最大**で4位（高く売りたい）を証明。
- プラチナ指輪をFVに据え、最大流入語句と一致させる。

## ⑦ ABテスト設計（公開後に最初に検証すべき優先順位）

CVへのインパクトと、実データの確度が高い順に並べる。

| 優先 | 検証対象 | A案 vs B案 | 根拠（実データ） |
|---|---|---|---|
| **1** | **オファー（手取りの見せ方）** | 「手数料無料」 vs 「**提示額＝手取り／後出し0円**」 | 手数料クラスタCTR最高(33%)＆業者名+手数料で不信。"無料"は競合と同質→差別化文言が効くか最優先で検証。 |
| **2** | **訴求（FV見出し）** | 「金買取・高価買取」総合 vs 「**プラチナ/純度別 今日いくら**」具体額提示 | 最大流入が「プラチナ指輪×価格×純度指定」。具体額FVが離脱を止めるか。 |
| **3** | **相場・概算の表示形式** | 静的な相場表のみ vs **その場シミュレータ/早見表** | `いくらで売れる`需要。実額を先に見せるとCVが上がるかは競合の隙＝検証価値大。 |
| **4** | **CTA** | 「WEB査定予約」単独 vs **電話＋WEBの2系統＋"額を聞いてから決められる"** | 既存運用文言が電話/WEB併記。即決層を取りこぼさないか。文言でリスク低減が効くか。 |
| **5** | **比較表示** | 比較なし vs **他社の減額項目との対比表（出張費/後出し手数料/キャンセル料）** | 不信層は業者比較中。正直な比較が信頼に変わりCVするか。誇大にならない範囲で検証。 |

テスト運用の注意：
- 現状は1日100表示規模。**1要素ずつ・十分な期間**で回す（同時多変数は今のボリュームでは判定不能）。
- 一次KPIは**CV率**、補助でCTRと「シミュレータ操作率／電話タップ率」をマイクロCVとして観測。
- まず①②（FVのオファー＆訴求）を固めてから③以降へ。FVがCV全体の支配項。
