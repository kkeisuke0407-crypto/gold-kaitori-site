# プラチナ買取LP デザインシステム（CV率コンセプト・実物根拠版）

> 目的：**オリジナリティではなくCV率最大化**。
> **本版は実機スクリーンショット9枚（競合のスマホ実画面）を一次根拠に改訂**。前版は検索スニペット＋業界慣行からの推定だったため、実物と食い違う箇所（特にCTA色）を訂正している。
> 土台の戦略（検索意図・LP構成・コピー）は自社の実広告データ(`docs/ad-data-analysis.md`)に基づくため不変。本書は**デザイン層のみ**を競合実物に合わせる。

---

## 0. 結論（実物で確定したCV率コンセプト）

競合スマホLP9枚を観察した結果、勝ちパターンの骨格は以下：

**「①特大の当日単価＋純度別相場テーブル＋推移チャート ②増額UPバースト(20〜30%UP)をCTA脇に ③用途別のCTA色(比較=緑/単一送客=赤) ④王冠TOP3で1位を突出 ⑤スマホ下部に固定CTA ⑥査定員写真＋安心バッジ ⑦超ロング・高情報量」**

— 余白を活かす"きれいなLP"は少数派（青クリーン型のなんぼや系のみ）。**大多数は情報量を盛り、相場とCTAを最も目立たせる**。

## 競合は2系統に割れる（実物分類）

| 系統 | 代表 | 配色 | 特徴 | CV型 |
|---|---|---|---|---|
| **A. 赤×白アグレッシブ型**（多数派） | おたからや・大吉系・プラチナ専門LP | 赤ヘッダー×白地、緑 or 赤CTA、オレンジUPバースト | キャンペーン帯／20-30%UP／相場テーブル＋チャート／査定員写真／王冠TOP3／超ロング | 単一送客 or ランキング |
| **B. 青×白クリーン信頼型**（少数・上位ブランド） | なんぼや系 | 青×白、余白多 | 「4つの安心」バッジ／法人・高級トーン／写真リッチ | ブランド信頼 |
| **C. 比較/ランキング・ポータル型** | マイベスト・ヒカカク・記事型 | **緑CTA**多数 | 王冠TOP3／横スクロール比較表／スコア根拠／PR表記 | アフィリ送客 |

> **自社LPの立ち位置**：アフィリ送客（まねきや vs おたからや）＝**C系（緑CTA）をベースに、A系の相場テーブル＋チャート＋UPバースト＋王冠TOP3を取り込むハイブリッド**が最適。

## ① 配色（実物で訂正）

### 実物で確認できた事実
- **比較/ランキング/ポータル型のCTAは「緑」が圧倒的多数**（スクショ1〜5）。
- **ブランド単一送客LPのCTAは「赤」が多い**（スクショ6〜8）。
- **赤はCTAではなく**ヘッダー帯・「今だけ」キャンペーン帯・緊急訴求に使われる。
- **オレンジ/黄は「20%UP」「30%UP」の丸いバースト**でCTA脇の増額インセンティブに固定。
- 青×白は少数（なんぼや系の高級・信頼トーン）。
- 金×クリーム/ベージュ＝金/貴金属専門の高級トーン。

> ⚠️ **前版の訂正**：前版は「暖色オレンジ/赤CTAが主流」としたが、**実物では比較型は緑CTAが主流**。自社LPは比較送客型なので**現状の緑CTAは競合と一致しており正しい**。オレンジへ変える必要はない。

### 推奨配色（自社LP＝比較送客型）
```
地色        : #FFFFFF / #FBF7EE（セクション交互）
メイン文字   : #16110A
主CTA(送客)  : 緑（現状維持）#2E7D52 系 / hover濃く  ← 比較型の定石。変えない
増額/緊急訴求 : オレンジ #F08A24 のバースト（「今日の単価」訴求や差額の可視化に転用可）
相場ハイライト: 背景 rgba(241,196,92,.16) / 枠 #F1C45C（黄）
プラチナ相場 : 寒色 #344D5A ／ 金相場 #B8860B
前日比      : 上昇#D33A2C(赤) / 下落#2E7D52(緑)  ※日本の株価色慣習・実物も色分け
1位カードCTA : 主CTA緑（最高彩度）。2位はアウトラインでトーンを落とす
```

## ② ファーストビュー（実物の配置）

### 競合FVに必ず入っている要素（スクショ確認）
1. **赤 or 金のヘッダー帯**＋「高価買取」「今だけ」
2. **当日の1g単価を特大数値**（例：プラチナ 9,652円 / 10,600円）
3. **「20%UP」「30%UP」の増額バースト**（CTA脇）
4. **CTAボタン**（緑 or 赤・全幅）
5. **実績/権威**（店舗数・東証上場・★評価・査定員写真）
6. 直下に**純度別相場テーブル**＋**価格推移チャート**

→ FV〜FV直下は**6〜8要素**。情報量は多い方が勝っている。

### 推奨レイアウト（自社LP）
現状FV（H1＋相場パネル＋CTA）は方向性OK。**追加で効くのは**：
- 相場パネルを**純度別テーブル形式**にして「相場感」を強化（競合は全部テーブル）
- 可能なら**推移チャート**（※価格履歴データが必要。無いうちは前日比表示で代替）
- 「今日の単価」を**バースト的に強調**（増額UPの代替として鮮度を訴求）

## ③ CTA（実物）

| 項目 | 実物の事実 |
|---|---|
| 色 | 比較型=**緑**／単一送客=**赤**。全幅・高さ大 |
| 形状 | 角丸（8〜12px）。矢印 or ☎アイコン付き多い |
| 文言 | 「無料査定」「今すぐ申し込む」＋脇に「最短」「無料」 |
| **増額バースト** | CTAの右上等に「**◯%UP**」丸バッジ＝行動の動機を併設 |
| **固定CTAバー** | スクショのロングLPで、スクロール時に画面下部固定CTAが定番（A系） |

### 推奨パターン（自社LP）
```
主CTA   : 緑（現状維持）/ 全幅 / 角丸12 / ☎アイコン / 直下「無料・その場で概算」
バースト : CTA脇に「今日の単価」or 概算差額を丸バッジで（増額UPの自社版）
固定バー(SP・新規): 画面下固定 2分割 [ ☎電話で概算(緑) | 概算を計算(濃色) ]
         FVのCTAが画面外に出たら表示。← 競合A系の定石・自社は未実装
```

## ④ フォーム（実物）

- ブランドLPは**簡易フォーム**（品目・名前・電話の数項目）or 電話/LINE誘導。
- **比較/アフィリ型（＝自社）はフォーム無し＝外部送客ボタン**。
- 自社の唯一の入力UI＝**その場概算計算機（純度・重さの2項目）**で正解。離脱最小。現状維持。

## ⑥ デザインシステム（実物根拠ルール）

### 見出し
- H1: 28〜40px / 900 / 2行以内 / `<br>`で改行制御。
- 数値（相場・金額）は**見出しより大きく**（競合の最大要素）。tabular-nums・nowrap。

### ボタン
```
主CTA(比較送客): 緑 #2E7D52系 / #fff / 700 / 角丸12 / 全幅(SP) / ☎ or →アイコン
               直下microcopy「無料・最短」。脇に増額/鮮度バースト(丸バッジ)
サブCTA       : アウトライン #344D5A
1位ボタン      : 主CTA緑(最高彩度)。下位はアウトラインでトーンを落とし視線を1位へ
最小タップ     : 高さ48px+ / 間隔8px+
固定バー(SP)   : 画面下固定2分割・z-index高・FVのCTA画面外で出現
```

### フォーム（＝概算計算機のみ）
```
入力2項目(純度select・重さinput)。input高44px+ / font16px(iOSズーム防止)。
計算ボタン=主CTA緑。結果パネル濃色＋金額特大＋直下に送客CTA。
```

### 比較表 / ランキング（競合の核）
```
方式 : 上部に1位2位カード + 下部に横スクロール比較表(ハイブリッド)。
1位  : 👑金王冠＋枠2px＋影＋「PR」小チップ＋緑ボタン。カードやや大。
2位  : 🥈銀王冠/細枠/アウトラインボタン/トーン控えめ。
比較表: 優位セル◎＋淡色付け、同等○。横スクロール(SP)。
PR表記: ヘッダ・各カード・表ヘッダ・脚注に控えめに(景表法)。順位訴求は弱めない。
```

### 相場表（最重要UI・競合は全部これ）
```
当日1g単価をページ最大級の数値で。Pt900/Pt950主役。
純度別テーブル(Pt1000/Pt950/Pt900/Pt850/K18/K24)＋更新日付＋出典リンク。
効く: 前日比(↑赤/↓緑)・「例:4gなら○円」換算・毎日更新ラベル・推移チャート(データ要)。
金額はnowrap・tabular-nums・はみ出し禁止。
```

### 査定員/権威/安心
```
査定員写真(女性)＝安心材料の定番(競合多数)。※自社はアフィリのため任意。
権威 : 店舗数/実績/★評価を数値バッジでCTA近傍に。
安心 : 「無料」緑バッジ固定。手数料0/出張0/キャンセル0をアイコン列挙。
青クリーン型の「4つの安心」バッジも上位ブランドの型。
```

### CTA（全体）
```
配置: FV/概算結果直下/手数料直下/比較カード内/流れ下/最終 + スマホ固定バー。
色  : 比較送客=緑で統一(他に流用しない)。
文言: 動詞＋無料/最短を密着。☎アイコン。脇に鮮度/増額バースト。
```
