# プラチナ買取LP デザインシステム（CV率コンセプト）

> 目的：**オリジナリティではなくCV率最大化**。金買取・プラチナ買取・買取比較の上位/出稿競合12〜20サイトを調査し、「勝っている競合が実際にやっているデザイン」を抽出し、それを組み合わせたルールに落とす。
> 調査ソース：`docs/ad-data-analysis.md`（自社広告実データ）＋競合デザイン調査2本（金買取 / プラチナ・買取比較）。
> 注記：競合サイトはbot対策(403)が標準のため、HEXや固定バー実装の一部は「当ジャンルで確立された慣行＋検索データ」からの推定を含む。確定が必要な値は実機DevTools確認で裏取りする前提。

---

## 0. 結論（CV率コンセプト1行）

**「今日の単価を一番大きく・暖色CTAを一番目立たせ・スマホ下部にCTAを固定し・1位を視覚的に突出させる」**
— 美しさ/独自性は捨て、この4点を最優先する。残りは competitorの最頻パターンに寄せる。

---

## ① 配色

### 競合で最も多い配色
| パターン | 採用層 | 用途 |
|---|---|---|
| **赤(メイン) × 白(地) × 暖色CTA(赤/オレンジ/黄)** | おたからや・バイセル・福ちゃん・大吉ほか大多数 | 査定誘導型LPの王道 |
| 黒 × ゴールド × 白 | なんぼや等の高級訴求 | ブランド感重視（CTRはやや弱い傾向） |
| 緑＝「無料」バッジ / 黄＝相場ハイライト・注意喚起 | ほぼ全社 | アクセント |
| 前日比の色分け：**赤＝上昇 / 緑・青＝下落**（日本の株価色慣習） | 相場表示サイト全般 | 「今が売り時」演出 |

### CTR/CVに影響していそうな色
- **高彩度の暖色CTA（赤/オレンジ）× 落ち着いた地色** の最大コントラスト＝クリック誘導の鉄板。
- **「無料」は緑バッジ**で固定化（ユーザーが一瞬で識別）。
- 相場の**当日単価は黒/濃色で特大**、前日比＋は赤で「上がってる＝今売ると得」を演出。

### 推奨配色（このLP）
> 現状LPは金×グリーン基調（`--green-deep`）で上品だが、**CTAの暖色コントラストが競合より弱い**のがCV観点の弱点。下記に寄せる。

```
地色      : #FFFFFF / #FBF7EE(セクション交互)
メイン文字 : #16110A(ほぼ黒)
プラチナ相場: #344D5A(プラチナの寒色) ※金は #B8860B 系
主CTA     : #E8491D（高彩度オレンジ寄り赤）/ hover #C73A12  ← 最優先で目立たせる
無料バッジ : #2E7D52（緑）＋白文字
相場ハイライト: 背景 rgba(241,196,92,.16) / 枠 #F1C45C（黄）
前日比上昇 : #D33A2C（赤）/ 下落 #2E7D52（緑）
リンク/補助CTA: アウトライン #344D5A
```
**ルール：主CTAの暖色は「ページ内で他に使わない」色にして、ボタン＝行動の色だと学習させる。**

## ② ファーストビュー（FV）

### 競合の配置要素・要素数（最頻）
全社FVに同居している要素（多い順）：
1. **即時性バッジ**「最短5分」「即日」「その場で現金」
2. **手数料無料の列挙**（査定/出張/送料/キャンセル＝無料アイコン群）
3. **本日の1g単価**（特大数値・更新日付つき）
4. **権威/実績**（店舗数・累計買取○万点・東証上場・★4.8）
5. **CTA（無料査定/電話）**＋電話番号を上部に
6. 申込チャネル複線（Web/電話/LINE）

→ FVの要素数は**5〜7要素**が標準。情報量は多め（日本の買取系は"そぎ落とし"より"安心材料の同居"が勝つ）。

### CTA位置・フォーム位置・相場位置（競合パターン）
- **CTA**：FV内に必ず1つ＋電話番号を最上部ヘッダーに。
- **相場表示**：FV右(PC)／FV直下(SP)に特大数値。更新日付を必ず添える。
- **フォーム**：ペライチ型は「フォームはFVに置かず、CTAタップ→電話 or 別フォーム」が多い（買取系は電話CVが主）。比較/アフィリ型はフォームを持たず**外部送客ボタン**。

### 推奨レイアウト（このLPはアフィリ送客型なのでフォーム無し）
```
[ヘッダー: ロゴ | (電話番号) | PR ]
[FV左] 即時性＋手数料無料の一行 → H1(今日いくら) → hero-alert(売るのは後で)
       → 主CTA(暖色)＋サブCTA(概算へ) → 安心3点
[FV右] 本日の単価パネル(Pt900/Pt950 特大, 更新日付, 例:4gなら○円)
```
→ 現状LPはこの構造を既に満たしている。**改善点はCTA色のコントラスト強化と相場数値のさらなる拡大のみ**（③④で具体化）。

## ③ CTA

### 競合の最頻パターン
| 項目 | 競合の主流 |
|---|---|
| 色 | 高彩度の暖色（赤/オレンジ）。緑も「進め」連想で併用 |
| サイズ | 横幅ほぼ全幅(SP)、縦パディング大（指で押しやすい44px+） |
| 形状 | 角丸（8〜12px）。完全な角丸ピル型も多い |
| 文言配置 | ボタン文言＝動詞＋無料（「無料査定」「今すぐ査定」）。**直上/直下に「最短5分」「出張費無料」を密着** |
| アイコン | 電話アイコン/LINEアイコンを併用 |
| **固定CTA** | **スマホ画面下部に追従バー（電話＋LINE/フォームの2分割）＝当ジャンルの定石** |

### CV率に効く点
- **固定CTAバーは買取系LPのCV率に最も効く要素の1つ**。現状のプラチナLPには**未実装＝最優先の追加候補**。
- CTA文言の直近に無料/最短を置くと心理障壁が一段で消える。

### 推奨パターン（このLP）
```
主CTA   : 背景#E8491D / 白文字 / 角丸12px / 全幅(SP) / padding 16px 24px / 影あり
         文言「電話でプラチナの概算を聞く」＋直下に小さく「無料・その場で概算」
サブCTA : アウトライン#344D5A（概算へスクロール / おたからや条件）
固定バー(SP, 新規): 画面下固定 2分割
         [ ☎ 電話で概算(暖色) | 概算を計算(濃色) ]  高さ60px, z-index高
         ※スクロールでFVのCTAが画面外に出たら表示
```

## ④ フォーム

### 競合の傾向
- 査定誘導型：フォームは**4〜6項目**（名前/電話/品目/任意でメール）。ただし**FVには置かず**、CTA後 or 下部。電話CVが主軸。
- **比較/アフィリ型（＝このLP）：自前フォームを持たず、外部公式へ送客ボタン**。フォーム最適化＝「ボタンの視認性とPR順位」に置き換わる。

### 推奨構成（このLP）
- **自前フォームは持たない**（アフィリ送客型の正解）。
- 唯一の"入力UI"＝**その場概算計算機**（純度select＋重さinput＋計算ボタン）。
  - 項目は**2つ（純度・重さ）だけ**に絞る＝離脱最小。現状実装どおりでOK。
  - 計算結果パネルの直下に主CTA（送客）を置く＝意図の高いユーザーをそのまま送客。現状実装済み。

## ⑥ デザインシステム（ルール）

### 見出し
- H1: 28〜40px(SP〜PC)/ weight 900 / 行間1.15 / 2行以内。日本語は`<br>`で改行制御（`text-wrap:balance`は全幅見出しのみ）。
- H2(セクション): kicker(12px大文字)＋H2(22〜28px)。中央 or 左。
- H3(カード): 18px / weight 700。
- **数値（相場・金額）は見出しより大きく**：相場特大28〜40px、tabular-nums、`white-space:nowrap`。

### ボタン
```
主CTA  : bg#E8491D / #fff / 700 / 角丸12 / pad16-24 / shadow / 全幅(SP)
         hover #C73A12。直下にmicrocopy(無料・最短)
サブCTA : outline #344D5A / bg透明 / 同サイズ
1位ボタン: 主CTA色。下位ボタンはアウトラインでトーンを落とす（視線を1位へ）
最小タップ: 高さ48px以上 / ボタン間8px以上
```

### フォーム（＝概算計算機のみ）
```
入力は2項目(純度select・重さinput)。label太字14px＋補助small。
input: 高さ44px+ / font16px(iOSズーム防止) / 枠#D8CCAD / 角丸10
計算ボタン=主CTA色。結果パネル(濃色#1F2937)＋金額#FFE9A8特大＋直下CTA。
```

### 比較表 / ランキング
```
方式: 上部に1位2位カード(2択) + 下部に横スクロール比較表 のハイブリッド。
1位 : 王冠(金)＋枠2px＋影＋「PR」小チップ＋暖色ボタン。カードやや大。
2位 : 王冠(銀)/細枠/アウトラインボタン/トーン控えめ。
比較表: 1行目見出し。優位セルは◎＋淡い色付け、同等は○。横スクロール(SP)。
PR表記: ヘッダー・各カード・表ヘッダ・脚注に控えめに（景表法）。順位訴求は弱めない。
スコア根拠を添えると納得感UP（任意）。
```

### 相場表（最重要UI）
```
当日1g単価を“ページ最大級”の数値で。Pt900/Pt950を主役、Pt1000/Pt850/K18/K24を従。
必須: 更新日付ラベル(例 2026年5月29日現在)＋出典リンク。
任意で効く: 前日比(↑赤/↓緑)、「例:4gなら○円」の換算、毎日更新ラベル。
グリッドは2×2 or 1列(SP)。金額はnowrap・tabular-nums・はみ出し禁止。
```

### 口コミ / 権威性 / 安心材料
```
口コミ: ★評価＋一言＋属性(年代/品目)。顔写真は任意(無くても可)。
権威: 店舗数/累計実績/受賞/メディアを“数値バッジ”で。CTA近傍に置き不安相殺。
安心: 「無料」は緑バッジで固定。手数料0/出張0/キャンセル0をアイコン列挙。
      女性査定員・個室・出張可などを安心材料として明示。
```

### CTA（全体ルール）
```
配置: ①FV ②概算結果直下 ③手数料直下 ④比較カード内 ⑤流れ下 ⑥最終 ＋ ⑦スマホ固定バー。
色  : 主CTA暖色は“行動の色”として他に流用しない。
文言: 動詞＋無料/最短を密着。電話CTAは☎アイコン。
固定バー: SPでFVのCTAが画面外に出たら表示。電話＋概算の2分割。
```
