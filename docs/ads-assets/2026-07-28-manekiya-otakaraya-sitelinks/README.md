# 金買取アセット設定（2026-07-28）

対象キャンペーン:

- `脳死AI金買取`
- `脳死AI金買取｜状況探索`

Google広告エディタに、番号順で各CSVをインポートする。

1. `01_GAE_ADD_SITELINKS_UTF8_BOM.csv`
2. `02_GAE_ADD_CALLOUTS_UTF8_BOM.csv`
3. `03_GAE_ADD_STRUCTURED_SNIPPETS_UTF8_BOM.csv`

`02` は広告グループ欄を含めず、`Campaign` 列でキャンペーン単位の関連付けを作成する形式にしている。旧版を取り込んでコールアウトが共有ライブラリだけに作成された場合も、修正版の `02` を再インポートすればよい。

サイトリンクは、公開済みの比較LP内アンカーを利用する。UTMの `utm_campaign` により、本体と状況探索のクリックを分けて確認できる。

構造化スニペットのヘッダーは、Google広告で選択できる `サービス` と `タイプ` を使用する（`対象` は使用しない）。
