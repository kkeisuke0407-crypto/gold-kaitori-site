## 設定値と根拠

| 項目 | 値 | 根拠 |
|---|---|---|
| 上限CPC | 400円 | 対象語の実売CPCは116〜277円。必要Rが1.3〜3.6%と低く、400円まで出しても損益分岐に余裕がある |
| 日予算 | 2,000円／キャンペーン | 在庫が1日22表示程度のため上限として機能する。**実消化は600〜1,200円/日の見込み** |
| マッチタイプ | 完全一致のみ | 金のみで比較すると完全一致 CVR 9.74%・CPA 2,183円に対し、フレーズ一致は CVR 4.46%・CPA 3,010円 |
| 入札戦略 | 手動CPC | CV母数が学習に届かないため、自動入札は使わない |
| 配信時間 | 9:00–20:00 | 成果地点が「通電後の査定予約」。受付は21時までだが、終了間際は通電しにくいため20時で切る |
| デバイス | モバイルのみ | 電話発信はほぼモバイル。PC経由で電話に至る確率が低い |

## 計測

Final URL に `?intent=<広告グループ別スラッグ>` を付与済み。`/kin-necklace/` と `/manekiya-otakaraya/` は
このパラメータを読んで `landing_intent` に反映するため、**GA4で広告グループ別に電話クリック率を分離できる**。

| 広告グループ | intent |
|---|---|
| AG01_18金ネックレス重量 | `k18_necklace_weight` |
| AG02_喜平ネックレス | `kihei_necklace` |
| AG03_金ネックレス売却 | `gold_necklace_sell` |
| AG01_ランキング比較 | `ranking_compare` |
| AG02_18金指輪 | `k18_ring_price` |

不正値・未指定時はページ固有ID（`kin_necklace` / `manekiya_otakaraya`）にフォールバックする。

## 既存キャンペーンの扱い

この2本を有効化する前に、**既存の課金キャンペーンは全て停止する**。特に以下は必ず止める。

- `CP01_プラチナ指輪_利益回収`（22,117円投下・**全額 案件対象外**）
- `金買取査定ナビ`（プラチナ部分15,654円・**全額 案件対象外**）
- `金AIMAX`（49,194円・CPA 3,784円・必要R 8.78%）

同じ語句が複数キャンペーンに重複していると自分同士で入札を競り上げるため、
`18金喜平ネックレス買取価格`（12キャンペーンに重複）などは新キャンペーンに一本化すること。
