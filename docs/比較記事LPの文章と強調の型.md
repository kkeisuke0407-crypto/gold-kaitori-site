# 比較記事LPの文章・強調・見出しの型

構成（セクションの並び）は案件で変わってよい。**変えないのはこっち** —— 見出しの立て方、文のリズム、強調の付け方。
ここが揃っていれば別商材でも同じ記事に見える。逆にここがブレると、構成をコピーしても別物になる。

全部 `public/manekiya-otakaraya/index.html` から**実測して抽出**したもの。構造の話は `docs/比較記事LPの雛形.md`。

---

## 0. まず数字（この密度を再現する）

| 項目 | 実測値 | 意味 |
|---|---|---|
| h2 | **16本** | 1本あたり本文5段落前後 |
| h3 | **23本** | 強み8＋強み5＋コツ5＋その他 |
| 素の `<p>` 本文 | **82段落 / 平均77字** | 中央値81字・最長135字。**150字を超えたら切る** |
| 1文 | **平均30字** | 205文。**40字超えたら読点で切るか2文にする** |
| `em-mark`（黄マーカー） | **20件** | ≒1セクション1〜2個。**これが上限** |
| `em-green` | **14件** | 得・無料・金額 |
| `em-red` | **17件** | 注意・条件・危険 |
| 素の `<strong>` | **235件** | 3色の**11倍**。通常強調はこれ。3色は特別扱い |

> 3色を増やすと全部同じ強さに見えてメリハリが消える。**素の `<strong>` が地の強調、3色は年に数回の切り札**という比率。

## 1. 見出しの型

### h2 の5パターン（実文 → 型 → 別案件への差し替え）

**A. 全角パイプ「｜」で「前置き｜核」**（16本中4本。この記事の看板パターン）

| 実文 | 型 |
|---|---|
| では本題です｜なぜ、この2社なのか | `では本題です｜なぜ、この{n}社なのか` |
| ここまでを踏まえて｜あなたはどちらから査定すべきか | `ここまでを踏まえて｜あなたは{読者の判断}すべきか` |
| まとめ｜結局どっちを選ぶ？ | `まとめ｜結局どっち{読者の言葉}？` |
| 金を売ったときの税金｜地金とアクセサリーで扱いが異なります | `{テーマ}｜{結論の要約}` |

左に**読者の現在地**、右に**そこで扱う問い**。左だけだと事務的、右だけだと迷子になる。

**B. 読者の問いをそのまま置く（`？` で終わる）**
- `今、金を売るべきか？` → `今、{商材}を売るべきか？`
- 検索窓に打つ言葉をそのまま使う。飾らない。

**C. ナビゲーション語で始める**（読者の手を引く）
- `まず、金の買取9社を比較しました` → `まず、{商材}の買取{n}社を比較しました`
- `まず、2社がどういう会社なのか`
- `ここで一度、売る前の迷いを整理します`
- 使う語：**まず／ここで一度／ここまでを踏まえて／では本題です**

**D. 言い切って許可を出す**
- `こんな業者は、その場で帰ってOKです` → 読者の不安に**許可**を出す形
- `最大30%UPは、電話申込限定です` → 特典＋条件を1行で確定させる

**E. 数字を入れる**
- `どの店を選んでも、損をしない5つのコツ`
- `まず、金の買取9社を比較しました`

**h2でやらないこと**：体言止めだけの見出し（`金買取の比較`）、キーワード詰め込み（`金 買取 おすすめ 比較 2026`）、煽り（`絶対に損しない！`）。

### h3 の3パターン

**A. `ラベル①｜内容` の連番型**（23本中21本）
```
強み①｜金の「重さ」だけで終わらせない査定
強み②｜査定の根拠を質問しやすい
コツ1｜その場で即決しない
弱み｜正直に3つ書きます
```
- ラベルは **強み／弱み／コツ** の3種。連番＋`｜`＋内容。
- 内容は**動詞で終える**（〜査定／〜しやすい／〜即決しない）。名詞止めより読者の行動に近い。
- ⚠️ 実ページは強みが `①②③`、コツが `1 2 3` で**表記が揺れている**。新規は丸数字に統一する。

**B. メタな宣言型**（信頼を作る位置に置く）
- `弱み｜正直に3つ書きます` ← 「これから不利なことを書く」と予告する。ここが記事の信頼の要。
- `利用前に確認したいこと`

**C. カギカッコ＋読点で溜める型**
- `「手数料無料」の、ほんとの話`
- 業界の常套句をカギカッコで引用 → 読点で一拍 → `ほんとの話` で裏を返す。

## 2. 強調の型（ここがいちばん再現しにくい）

**3色は「目立たせたいから」使うのではなく、情報の種類で決まっている。** 実測すると使い分けが明確に出た。

### `em-mark`（黄マーカー）＝ **文まるごと**。読者の判断そのもの

付いているのは単語ではなく**文・節**。文末が「〜てください」「〜ません」「〜分かります」「〜抜け出せます」で終わる。

```
・住んでる場所で決めてください。
・「言い値で売る」から抜け出せます。
・どっちに転んでも、タダで数字が1つ手に入ります。
・買い叩かれる確率がガクッと下がります。
・金は逃げません。
・「いくらか」は今日タダで分かります。
・その場で金額を聞いて、納得したらその場で現金。
```
**ルール**：1セクションに1〜2個。そのセクションを1行に要約したときの**その1行**に付ける。単語には付けない。

### `em-green` ＝ **数字入りの名詞句**。得・無料・特典

```
・出張査定が全国対応で、出張料・査定料・手数料はぜんぶ無料
・最大30%UP＋金の手数料10%が無料
・12万円 ／ 57万200円 ／ 年間合計で50万円の特別控除
・業者向けの取引価格
・聞くだけならタダ
```
**ルール**：金額・率・「無料」「ゼロ」「タダ」を含む短い句。文全体を緑にしない（得が薄まる）。

### `em-red` ＝ **否定文・リスク語**。注意・条件・危険信号

```
・検索の上に出てる店＝高く売れる店、ではありません。
・これからの価格は、誰にも断言できない
・地方だと「宅配で送るしかない店」が大半です。
・返送料は自己負担
・その場は帰っていい
・対象店舗・品目・上限がバラバラ
・店ごとの当たり外れは正直あります
```
**ルール**：`〜ではありません` `〜できない` `自己負担` `バラバラ` `対象外`。
**推薦社の弱みにも赤を使う**（`店ごとの当たり外れは正直あります`）。赤を他社叩きだけに使うと広告になる。

### 素の `<strong>`（金の細線）＝ 地の強調

235件。**事実・固有名詞・数値・条件**に付ける。迷ったらこれ。

### やってはいけない使い方

- ❌ 同じ段落に3色を全部入れる（どれが結論か分からなくなる）
- ❌ `em-mark` を1セクションに3個以上
- ❌ 見出しの中で3色を使う（h2/h3は既に十分目立つ）
- ❌ 赤を他社批判にだけ使う

## 3. 文と段落の型

### リズム
- 1文**30字**、1段落**2〜3文（77字）**。150字を超えたら段落を割る。
- 短文を単独段落で置いて溜めを作る：`これが現実です。` `正直、しんどい。` `タダですし。`
- **改行 `<br>` は語句の途中で切らない**。`kin-punch` `kin-intro` `kin-fv-conclusion` は必ず実機幅（390/360/320px）で見る。

### 書き出しのパターン（実文から）
| 型 | 実文 |
|---|---|
| 読者の内心を代弁 | `……で、結局どれを信じればいいの？って話ですよね。` |
| 秘密の共有 | `ここ、あまり言われないんですが——` |
| 先回りの否定 | `べつに今すぐ売らなくていいんです。ただ、` |
| 自分の判断を出す | `正直、これがいちばん効きます。` |
| 事実の提示から入る | `これが現実です。どんな店でも、` |

### 口語マーカー（実測の出現数）
`んです`6 / `正直`4 / `……`3 / `じゃなく`3 / `わけ`2 / `ですよね`1 / `よね`1 / `べつに`1

→ **1記事あたり合計20回程度**。多すぎると軽薄、ゼロだとAI文になる。この密度が基準。

### 二重ダッシュ `——` の使い方
`ここ、あまり言われないんですが——地方だと「宅配で送るしかない店」が大半です。`
`ここがいちばん説得力あると思うんですが——買取の専門メディアが、`

**前置き → `——` → 核心**。溜めを作る唯一の記号。1記事2〜3回まで。

## 4. ブロック別の定型フレーズ

| ブロック | 実文 | 型 |
|---|---|---|
| FV結論 | 結論から言うと、／最初に見るべき候補は、この2社で大丈夫でした。 | `結論から言うと、` ＋ `最初に見るべき候補は、この{n}社で大丈夫でした。` |
| 筆者・書き出し | この記事、正直に書きますね。 | そのまま流用可 |
| 筆者・問い | いちばん知りたいのは「結局、いくらで売れるの？」なのに。 | `いちばん知りたいのは「{読者の一番の疑問}」なのに。` |
| 筆者・調査量 | 主要9社を1社ずつ、公式の買取条件・手数料・実績・口コミまでぜんぶ調べて、実際に査定にも出して | 数を必ず入れる。**やっていないことは書かない** |
| 導入・軸の宣言 | 見たのは「で、あなたの手元にいくら残るのか」だけです。 | `見たのは「{唯一の判断軸}」だけです。` |
| 比較表リード | そのうえで、最後の列だけは「金だけを売るなら、どこから査定するか」を結論にしています。 | 表の読み方を1行で指定する |
| 選定理由の見出し | まねきやが遠い地域は、じつは選択肢がほとんどない | `じつは` `あまり言われないが` で意外性を出す |
| 分岐の質問 | 最寄りで、まねきやの店頭・出張査定を受けられますか？ | **はい/いいえで答えられる1問**にする |
| パンチライン | 相場を見て、／明細を聞く。 | 2行・各10字以内・動詞で終える |
| 弱みの前置き | 弱み｜正直に3つ書きます | 数を宣言してから書く |
| まとめの背中押し | いま売らなくて、いいんです。でも「いくらか」は今日タダで分かります。 | `{行動しない許可}。でも{タダで得られるもの}。` |

### CTA見出し（7箇所。全部違う文にする）

実文：
```
1. まずは、いくらになるかだけ。
2. 気になったら、まず1社目の金額を聞いてみましょう。
3. 最寄りで店頭・出張査定を選べるなら、まずまねきやへ。
4. 5つのコツを踏まえて、まずは1社目の金額を確認してみましょう。
5. 査定は無料。金額に納得できなければ、断って構いません。
6. 流れが分かったら、あとは申し込むだけ。まずは金額の確認から。
7. まずは、手数料込みでいくらになるか。
```
**型**：①行動を最小化（`〜だけ。`）②直前セクションを受ける（`5つのコツを踏まえて` `流れが分かったら`）③断る許可（`断って構いません`）。
**同じ文を7回使わない。** 直前に読んだ内容を受けると押しつけにならない。

## 5. AIっぽい文 → 言い換え

| ❌ AIっぽい | ✅ この記事の文体 |
|---|---|
| 〜と考えられます／〜な可能性があります | 〜です／〜ません（言い切る） |
| 重要なポイントとして、以下の3点が挙げられます | 見るのは3つだけです |
| 適切に判断することが推奨されます | 金額を聞いてから決めればいいだけ |
| ご検討されることをおすすめいたします | まずは、いくらになるかだけ。 |
| 多くのユーザーから高い評価を得ています | 実際に査定に出した5例中2例が相場の上限を超えました |
| 一般的に、金の価格は変動する傾向があります | これからの価格は、誰にも断言できない |
| いかがでしょうか | （書かない） |
| まとめると、以下のようになります | まとめ｜結局どっちを選ぶ？ |

**判定基準**：主語が「一般的に」「多くの人が」になっていたらAI文。
`筆者が調べた結果` か `読者がやること` のどちらかが主語になっているのが正しい。

### ただし言い切ってよい範囲は決まっている

| 言い切れる | 言い切れない（景表法） |
|---|---|
| 買い叩かれる確率がガクッと下がります | この店が一番高く売れます |
| 公式にレートを公開しています | 業界最高値です |
| 5例中2例が相場の上限を超えました（＋特定の取引例の注記） | 誰でも相場以上で売れます |
| 確認できたのはこの2社でした | 他社は安いです |

**攻めるのは表現。事実の断定はゆるめない。** 読者の行動の効果は断言でき、店の優劣は断言できない。

## 6. 別商材へ差し替えるとき、触る語

商材が変わったら**この語だけ**を置き換えれば文体は保たれる。

1. **商材名**（金 → プラチナ／ブランドバッグ／時計）：h2の`{商材}`、`あなたの{商材}、今いくら？`
2. **判断軸**（最終手取り）：商材が変わっても手取りが軸なら不変。相場のない商材は「状態の見方」に置き換える
3. **査定要素**（品位・重量・石）→ 商材固有の評価要素（型番・付属品・年式）
4. **業界の常套句**（業界最高値・高価買取）→ そのジャンルの実際の広告文を検索して拾う
5. **危険信号**（即決を迫る・明細を出さない）→ ジャンル共通なのでほぼ流用可
6. **エリアの論拠**（宅配しかない／返送料自己負担）→ 商材の配送リスクに合わせる

**先に決めるのは2つだけ**：`唯一の判断軸`（＝em-markに何を書くか）と`分岐の1問`（＝はい/いいえで2社に割る質問）。
この2つが決まれば、あとは上の型に流し込める。
